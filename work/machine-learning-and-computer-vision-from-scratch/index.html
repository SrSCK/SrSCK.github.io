Machine Learning and Computer Vision from Scratch

About seven months of self-directed study with one of my professors, from the basics of programming to neural networks and computer vision, writing nearly all of the code myself.

Built
I implemented least-squares regression, Otsu thresholding and RANSAC in NumPy, and trained neural networks on CIFAR-10 with my own dropout and L1 and L2 regularization before moving to convolutional networks and PyTorch.
How
I wrote nearly all of this code myself, often without libraries, so that each model was built from the mathematics up.
Context
Self-directed study alongside my degree, October 2025 to April 2026
Stack
Python, NumPy, Matplotlib, PyTorch, OpenCV

I started with a 12-week course in Python fundamentals, from loops and recursion to object-oriented programming and NumPy, and finished it with a small personal finance planner split into modules. I then worked up to machine learning and computer vision. I implemented least-squares regression, Otsu thresholding and RANSAC in NumPy, and trained neural networks on CIFAR-10 with my own dropout and L1 and L2 regularization before moving to convolutional networks and PyTorch. On the vision side I worked through edge and corner detection, HOG and SIFT features, template matching and panorama stitching, and went on to object detection. I wrote nearly all of this code myself, often without libraries, so that each model was built from the mathematics up.
