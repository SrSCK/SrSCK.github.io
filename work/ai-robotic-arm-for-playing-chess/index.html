AI Robotic Arm for Playing Chess

Type
Group project

A group project to build an autonomous robot that can play a physical game of chess against a human.

  • Implemented a CNN-based move prediction model to analyze the board and determine the best move.

  • Processed board images from a camera using OpenCV for real-time piece detection and board state recognition.

  • Calculated inverse kinematics and wrote the control logic to translate the AI's move into precise robotic arm coordinates.
