The idea

Teams that use several agents (Claude Code, Codex, Cursor, Hermes) end up with context scattered across tools. teambrain keeps each project's linked notes and agent history in the cloud. Any MCP-capable agent can pull project context and write back what it did, and teammates, technical or not, watch it live in a browser. Code stays on each person's machine.

What I built

  • A data model of eight tables (workspace, member, project, note, link, attachment, activity, invite) with row-level security policies on every table.
  • An MCP server over streamable HTTP with three tools (list projects, pull context, push context), workspace tokens stored only as SHA-256 hashes, and a rate limit of 60 requests per minute per token. I verified it connected to Claude Code.
  • A live, workspace-wide agent activity feed as the signature feature, grouped by actor with colour-coded avatars and per-action icons.
  • Write modes for agent edits, with pending badges so people can see what still needs approval.
  • Notes with wiki-style links and autocomplete, magic-link sign-in and file attachments.

A decision I made on purpose

Context retrieval is two steps in version one. The agent first sees note titles, then picks what to read. I left embeddings and hybrid search for a later version to keep the six-week build small and predictable.

A security finding

While testing, I found that the server connected to the database as the table owner, which silently bypassed the row-level security I had written. The real guard was the app's own data-access layer. I documented this rule for every future query, and in a later fix made the browser's database roles read-only.

Honest limits

  • It is a test build, not a finished product, and it has no paying users.
  • Email invitations only reach the owner's address until a domain is verified.
  • Some keyboard interactions in the editor could only be verified by unit tests, not by automated browser tests.

What I took away

The interesting problem is not storing notes. It is letting several agents share one memory without stepping on each other, and making their work visible enough that people can trust it.
